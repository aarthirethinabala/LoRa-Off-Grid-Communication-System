# LoRa-Off-Grid-Communication-System
An ESP32 based off grid communication system using RA-02 LoRa modules, OLED displays, and keypad input for local communication without cellular or internet connectivity.

## Project Status
Work in Progress

## Overview
This project is designed to provide short-range local communication in areas where cellular networks and internet connectivity are unavailable.
The system uses ESP32 microcontrollers and RA-02 LoRa transceiver modules to exchange messages between independent communication nodes. OLED displays are used to display messages, while a keypad provides user input.
Unlike a conventional internet-based communication system, the project is designed to operate without relying on a central cloud server or cellular network.

## Hardware
- ESP32
- RA-02 LoRa module
- 0.96-inch OLED display
- Keypad
- Antenna
- Power supply

## Planned System
The system consists of multiple communication nodes capable of transmitting and receiving messages through LoRa.
Each node is intended to:
- Accept text input through a keypad
- Transmit messages using LoRa
- Receive messages from another node
- Display received messages on an OLED
